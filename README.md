##  Apresentação da Loja & Preços
A NutriStore é um e-commerce simulado focado em nutrição, estética minimalista e alta performance esportiva:
- **100% Whey Protein (900g):** R$ 130,00
- **Creatina Monohidratada (300g):** R$ 85,00
- **BCAA Amino Powder:** R$ 55,00

## Tecnologias e Instruções de Execução
- **AULAS:** Desenvolvido puramente em HTML, CSS e JavaScript.
- **Execução:** Abra o arquivo `index.html` diretamente em qualquer navegador moderno e clique no botão de simulação para rodar os prompts ativos.

##  Testes Realizados
- **Entrada nula:** Verificação do comportamento do sistema ao receber quantidades zeradas em todos os prompts, disparando o alerta de bloqueio.
- **Higienização de dados:** Tratamento contra caracteres de texto inseridos nos campos numéricos através da função `isNaN()`.
- **Validação de ponto flutuante:** Conferência da formatação de strings monetárias via método `.toFixed(2)`.
